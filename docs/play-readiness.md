## Current Google Play requirement

Source (read 2026-10-03): https://developer.android.com/google/play/requirements/target-sdk

- From 2026-08-31, new apps and app updates must target Android 16 (API 36) or higher (Wear OS/Automotive: 35; TV/XR: 34).
- Existing apps must target API 35+ to stay available to new users on newer devices.
- An extension to 2026-11-01 can be requested in Play Console.

## Signing: DEBUG (not production)

`eas-build.yml` builds `assembleRelease` with the Expo template's debug keystore (no secrets wired). Consequences:
- Fine for sideload testing; NOT acceptable for Play. Play needs an upload key (and Play App Signing).
- Switching keys later forces testers to uninstall (the signature changes) and loses local saves, as the workflow header already warns. Choose the final upload key BEFORE wider testing.
- Production signing must read named secrets and fail hard when absent. It is not wired yet. Never commit key material. OWNER owns custody.
