# Physical-device test checklist (owner)

Run on the installed APK after the update banner/Restart picks up the latest
OTA. Settings > About > Build & update details shows the running update.
Report anything off with Send report (Settings or the error screen).

## Downhill
- [ ] Hold-to-steer, Carve, Jump (tap and hold), Flip: controls feel direct, nothing sticks.
- [ ] Take kickers/cliffs: no jump without a take-off; no automatic second jump on landing.
- [ ] Land flips and spins clean and bad: bail + summary look right.
- [ ] Hit a tree/rock: crash screen, rider lies on the snow.
- [ ] Camera stays behind the rider on steep slopes and after landings; no clipping into the snow.
- [ ] Frame rate stays smooth for a 3+ minute run (note the phone model if not).

## Half-pipe
- [ ] Intro card shows once per profile; run is paused behind it.
- [ ] Walls, lip launch, rings, combo, switch stance; no launch without a jump.

## Lifecycle
- [ ] Home button mid-run: run pauses; return and resume works.
- [ ] Swipe the app away mid-run, reopen: "Run interrupted", Collect banks it once.
- [ ] Android Back on every screen goes back; only the main menu leaves the app.
- [ ] Rotate to portrait on menus: readable, nothing clipped.
- [ ] Lock the phone for a minute during a run and unlock.

## Data
- [ ] Create, rename, delete a profile (delete asks first).
- [ ] Balance and upgrades survive a force-stop and a reboot.
- [ ] Two profiles stay separate (stats, shop, dailies).

## Update
- [ ] About shows app and update versions.
- [ ] With Wi-Fi on, a published update downloads and applies from the main menu (not mid-run).
- [ ] Airplane mode: the game plays; update status says offline.

## Error / recovery
- [ ] Low-memory behaviour: open many apps, return: game remounts (no blank screen).
- [ ] Send report opens an email draft with build rows.

## UI
- [ ] Shop: buying keeps scroll position; can't-afford shakes and says "Need N".
- [ ] Numbers are grouped (1,234); icons are drawings, no stray emoji boxes.
- [ ] Back/primary buttons stay visible on long screens (Stats, Shop).
- [ ] Music, SFX sliders and Vibration toggle work and persist.
