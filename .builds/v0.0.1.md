# v0.0.1 — first APK build

First sideload-ready build of Snow. Captures the v1 skeleton + first
gameplay pass:

- Humanoid rider on a snowboard (orange jacket, blue pants, dark beanie).
- Carve-style steering with auto-center on stick release.
- Snow dust plume off the board, ribbon trail behind on the snow surface.
- Open-world 2D chunk streaming (80m × 80m chunks, no lateral boundary).
- Procedural rocks (hazards), kickers (forced launch ramps), and gold
  coin pickups per chunk.
- Hold-to-charge JUMP, hold-in-air FLIP. Coloured action buttons, dark
  stick + score badge for visibility on snow.
- Local profiles via IndexedDB; coins bank into the active profile on
  fall and persist across launches.
- "You fell" overlay shows distance, coins collected, and flips landed.

From this point on, gameplay/asset tweaks ship via EAS Update OTA. New
APK builds only when native deps change, asked-for explicitly.
